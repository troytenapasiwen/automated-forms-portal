# Automated Forms Portal

A centralized digital platform for creating, submitting, reviewing, and approving employee forms. Developed as an internship project to help streamline internal company workflows and reduce reliance on paper-based processes.

## Overview

The Automated Forms Portal provides a centralized workspace where administrators can manage forms and department heads can create or upload forms for employees to complete and submit.

The system supports digital form submission and approval workflows, making internal documentation more organized and accessible while reducing manual paperwork.

## Features

- **Centralized Form Management** - HR administrators can manage company forms through a single platform.
- **Departmental Form Creation** - Department heads can create or upload forms for their respective workflows.
- **Digital Form Submission** - Employees can complete and submit forms online.
- **Approval Workflow** - Submitted forms can go through the assigned approval process.
- **Consolidated Approval Document** - Generates a file containing the signatures of all assigned approvers once the required approvals are completed.
- **Paperless Processing** - Supports digital handling of internal documents, including sick leave and vacation leave forms.

## Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Styling:** Tailwind CSS
- **Backend and Database:** Firebase, Cloud Firestore

## Purpose

The project was developed to help digitize internal company processes, simplify employee form submissions, and make document approval workflows more efficient.
